# Notch — план разработки

Фоновый агент для macOS: панель у верхнего края экрана (вокруг нотча),
раскрывающаяся по наведению, с набором модулей.

## Архитектурные решения

- Swift 6 + SwiftUI, окно — `NSPanel(.nonactivatingPanel)` уровня `.statusBar`.
- Агент без Dock (`setActivationPolicy(.accessory)`), статус-айтем для выхода.
- Окно всегда размером с раскрытую панель; в схлопнутом виде
  `ignoresMouseEvents = true`, чтобы клики проходили в меню-бар.
- Работает и на экранах без нотча — виртуальный вырез по центру верха.
- Без App Sandbox (буфер обмена, AppleEvents) → раздача Developer ID + нотаризация.
- Модуль = тип, реализующий `NotchModule`; ядро о модулях ничего не знает.
- Хранилище: SwiftData (буфер, заготовки, полка).

## Фазы

- [x] **0. Скелет.** Панель, геометрия нотча, раскрытие по наведению,
      левый рейл с иконками модулей, заглушки содержимого.
- [x] **1. Каркас модулей.** Окно настроек, локализация (англ — база),
      вкл/выкл и порядок модулей, сохранение выбранной вкладки, высота
      панели по запросу модуля, отклик при появлении (звук + вибро).
- [x] **2. Заготовки + Буфер.** Заготовки с редактором в настройках; история
      `NSPasteboard` с опросом `changeCount`, закрепление, удаление,
      отсев `org.nspasteboard.ConcealedType`. Осталось на потом: поиск
      по истории и горячая клавиша на открытие буфера.
- [x] **3. Полка.** Drag in/out, мультивыбор, «Снять выбор», «Убрать»,
      «Очистить полку», закладки вместо путей, автоотсев исчезнувших файлов.
- [x] **4. Музыка.** Два провайдера с автовыбором: `MediaRemote` (любой
      источник, но возможно закрыт entitlement'ом) и AppleScript к Music
      и Spotify. Кто реально отвечает — видно в Настройках › О программе.
      Обложка, трек, прогресс, транспорт.
      Запасной путь — адаптеры Music.app / Spotify через ScriptingBridge.
      Протокол `NowPlayingProvider`. Обложка, скраббер, транспорт,
      устройство вывода через CoreAudio.
- [x] **5. Календарь + Перевод.** EventKit (ближайшая встреча + список на
      неделю, запрос доступа прямо в панели) и `Translation` на устройстве.
- [~] **6. Раздача.** Сделано: автозапуск через `SMAppService`, глобальные
      горячие клавиши (Carbon, без «Универсального доступа») с записью
      сочетания в настройках, поиск по истории буфера, закрытие по Esc.
      Конвейер подписи Developer ID, нотаризации и DMG готов
      (`Scripts/notarize.sh`, его зовёт `release.sh`) и проверен под
      Hardened Runtime. Осталось: сам сертификат Developer ID (платный
      Apple Developer Program) и Sparkle — ему нужна публичная лента
      обновлений, а репозиторий пока закрытый.

- [x] **7. Мелочи под рукой.** Заметка на полях (одно поле, сохраняется
      само), «Система» — процессор, память, сеть и диск из ядра, без
      разрешений и с опросом только пока модуль открыт. Горячая клавиша
      теперь у каждого модуля, а не только у буфера: старый ключ
      `openClipboard` переезжает в `module.clipboard`. Файл, поднесённый
      к вырезу, раскрывает панель на полке — схлопнутая панель не
      принимает мышь, поэтому перетаскивание ловится опросом буфера
      перетаскивания (`DragWatcher`), а не `registerForDraggedTypes`.

- [x] **8. Зеркало.** Превью камеры в панели (AVFoundation): основная
      камера системы (`systemPreferredCamera`), кадр 16:9 со скруглением,
      отзеркален через своё соединение слоя превью. Доступ спрашивается
      прямо в панели, отказ ведёт в Конфиденциальность › Камера. Сессия
      живёт только пока модуль на экране — свернули панель, сменили
      вкладку или открыли настройки, и огонёк камеры гаснет; запуск и
      остановка идут по своей очереди, не на главном потоке.

- [x] **9. Спросить ИИ.** Чат и правка текста из буфера на модели Apple
      Intelligence (`FoundationModels`) — на устройстве, без сети, история
      только в памяти. Модуль `@available(macOS 26, *)` и попадает в
      каталог только под `if #available`: на macOS 15 его нет ни в рейле,
      ни в настройках, ни в горячих клавишах; минимум приложения не поднят,
      фреймворк линкуется слабо. Ответ идёт потоком, короткая история
      сессии, «Очистить» в строке заголовка. Быстрые действия над буфером —
      «Переписать», «Сократить», «Исправить ошибки», «Перевести на
      английский» — каждое в своей сессии, результат с кнопкой
      «Скопировать». Apple Intelligence выключен, Mac не подходит, модель
      ещё качается — свои пустые состояния, первое ведёт в настройки.

- [x] **10. Напоминания.** EventKit, `EKEventStore` один на приложение —
      его делят Календарь и Напоминания. Невыполненные из всех списков по
      сроку (без срока — в конце), просроченное красным, точка цвета
      списка, когда списков больше одного. Галочка ставится сразу, а в
      базу уходит через 1,8 с — второй тап до этого её снимает; ушёл с
      экрана раньше — досохраняется. Поле внизу добавляет напоминание в
      список по умолчанию. Доступ (`requestFullAccessToReminders`)
      спрашивается в панели, отказ ведёт в Конфиденциальность ›
      Напоминания. Выборка и подписка на `.EKEventStoreChanged` — только
      пока модуль на экране. Цвет — голубой, иконка рейла — `checklist`.

- [x] **11. AirDrop с полки.** `NSSharingService(.sendViaAirDrop)`. Выбора
      на полке нет (файл тянут или зажимают), поэтому кнопка в строке
      заголовка шлёт всю полку, а один файл — из контекстного меню записи
      (там же «Показать в Finder» и «Убрать с полки»). Закладки
      разворачиваются заново прямо перед отправкой, доступ по закладке
      открывается и закрывается вокруг неё. `canPerform` гасит кнопку,
      когда AirDrop выключен. Агент без Dock активируется на время отправки,
      чтобы окно выбора встало впереди и с фокусом, а после — фокус уходит
      обратно. Панель держится открытой (`NotchPanel.holdOpen`), пока окно
      AirDrop не закрыто или приложение не потеряло фокус; Esc в это время
      достаётся окну AirDrop.

- [x] **12. Быстрые команды.** Своего API нет — системная утилита
      `/usr/bin/shortcuts`: `list --show-identifiers` (идентификатор берётся
      с конца строки, имя может содержать скобки) и `run <идентификатор>`,
      оба вызова не на главном потоке. Поиск в строке заголовка, щелчок по
      строке запускает команду — крутилка, затем галочка или красный
      треугольник с первой строкой ошибки в подсказке. Звезда (под курсором
      и в контекстном меню) закрепляет команду сверху; избранное — в
      `UserDefaults` (`shortcuts.favorites`). Список читается только пока
      модуль на экране и кэшируется на 30 с между открытиями, «Обновить» —
      в строке заголовка. Особых прав не нужно, проверено под Hardened
      Runtime. Цвет — янтарный, иконка рейла — `square.2.layers.3d`.

- [x] **13. Конвертер.** Единицы через `Measurement`: длина, масса,
      температура, объём, скорость, площадь, данные, время (сутки и
      недели — свои `UnitDuration`). Величины — значками в ряд, у
      выбранной подпись. Слева поле «из» и итог «в» со своими меню единиц
      и кнопкой «поменять местами», справа то же число во всех единицах
      величины; щелчок по значению копирует «число обозначение» через
      `ClipboardStore.copy`. Разбор прощает: «1,5» и «1.5» одинаковы,
      пробелы разрядов пропускаются, в английском «1,000» — тысяча.
      Числа и названия единиц — на языке интерфейса. Величина, число и
      пара единиц у каждой величины помнятся (`converter.*` в
      `UserDefaults`). Валют нет — без сети курс не узнать. Цвет —
      пурпурный, иконка рейла — `arrow.left.arrow.right.square`.

- [x] **14. Эмодзи.** Сетка по разделам системной палитры (около 1350
      знаков, без цветов кожи и сотни профессий), над ней значки разделов —
      прокрутка к разделу, справа название того, что под курсором. Поиск в
      строке заголовка по началу слов: английские названия даёт сама
      система (`CFStringTransform` с `kCFStringTransformToUnicodeName`,
      склейки и селекторы вариантов выкинуты), флаги собираются из кодов
      стран и называются через `Locale` на обоих языках, русские слова —
      короткий словарь для ходовых («огонь», «спасибо», «ок»). Щелчок
      копирует через `ClipboardStore.copy`, недавние (32, `emoji.recent`)
      встают первым разделом — с задержкой, чтобы сетка не сдвигалась под
      курсором. Цвет — лимонный, иконка рейла — `face.smiling`.

- [x] **15. Звуки фокуса в таймерах.** Под пресетами — «Фоновый звук»:
      без звука, дождь, кафе, белый, розовый и бурый шум, ползунок
      громкости (квадратичный — середина звучит серединой). Файлов нет:
      всё синтезируется в `AVAudioSourceNode` — розовый по Келлету, бурый
      интегрированием, дождь — полосовой розовый шум и капли по Пуассону
      со своим местом в стереопанораме, кафе — бурый шум в полосе голоса с
      «слоговыми» огибающими и редким звоном стекла. Звучит только пока
      идёт таймер: `didSet` у `isTimerRunning` поднимает и гасит звук на
      пуске, паузе, сбросе и конце отсчёта; без идущего таймера выбор
      только запоминается (`timers.focusSound`, `timers.focusVolume`).
      Появление и затухание — плавный подъезд уровня внутри синтеза
      (~1 с), движок глушится после затухания. Узел собирается в
      `nonisolated` функции: замыкание из метода `@MainActor` роняло бы
      приложение проверкой актора с аудиопотока.

- [x] **16. Телепромптер.** Текст правится в поле, как заметка на полях,
      и хранится в `teleprompter.json`; кнопка «Готово» переводит в
      суфлёр. Текст едет вверх узкой колонкой по центру, строка чтения —
      у верхней кромки, сразу под камерой; прочитанное гаснет вверху, не
      прочитанное проявляется снизу. Положение считается по часам (точка
      отсчёта + скорость), кадры даёт `TimelineView(.animation)`, на паузе
      расписание стоит. Скорость в «разах» от кегля (1× — полстроки в
      секунду): колесо и ± / ↑↓ на ходу, без скачка текста; на паузе колесо
      листает. Пробел — пуск и пауза, R — в начало, Esc сначала
      останавливает. Пульт внизу модуля (пуск, в начало, кегль, зеркало
      для стекла суфлёра, правка, скорость) прячется, пока текст едет и
      курсор не над ним. Пока текст едет, панель держится открытой
      (`NotchPanel.holdOpen`); дочитал до конца, ушёл с вкладки или
      свернул панель — встаёт и отпускает. Скорость, кегль и зеркало — в
      `UserDefaults`. Цвет — сланцево-голубой, иконка рейла —
      `text.viewfinder`.

## Открытые вопросы

- ~~История буфера в открытом JSON~~ — шифруется AES-GCM, ключ в Связке
  ключей; есть опция не хранить её на диске вовсе.
- `MediaRemote` закрыт entitlement'ом (проверено: Control Center видит
  сессию, наш процесс получает pid 0). Метаданные из браузера получить
  нельзя; управление работает через медиа-клавиши.

## Запуск

Для разработки хватает голого бинарника:

```
swift build && ./.build/debug/Notch
```

Но системные разрешения (Календарь, Автоматизация) работают только из
настоящего бандла — его собирает скрипт:

```
./Scripts/build-app.sh && open build/Notch.app
```

Выход — через иконку в меню-баре.
