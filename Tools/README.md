# Инструменты

## mrspike.swift — разведка MediaRemote

Проверяет, отдаёт ли приватный `MediaRemote.framework` данные о том, что
играет в системе. От этого зависит, сможет ли модуль «Музыка» видеть
произвольный источник (браузер, плеер) или придётся ограничиться
адаптерами к Music.app и Spotify.

Запускать **во время воспроизведения** — иначе пустой ответ не отличить
от закрытого доступа:

```
swiftc -o /tmp/mrspike Tools/mrspike.swift && /tmp/mrspike
```

Читается так:
- «ВЕРНУЛ ДАННЫЕ» — доступ есть, делаем универсальный провайдер;
- «пуст» при играющей музыке или «ТАЙМАУТ» — доступ закрыт,
  идём через ScriptingBridge к конкретным плеерам.
